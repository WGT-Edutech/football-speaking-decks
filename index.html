▶ Adding a future football deck
  1. Build the deck as a single .html file using the same template (dark theme, data-slide sections, bottom nav, deckSlug for progress).
  2. Drop it in this folder next to index.html.
  3. Add one object to the DECKS array at the top of the <script> in this file — the card grid is generated from that array, so no HTML edits are needed.
  4. Set the deck's own home link to index.html so the “Back to Portal” button returns here.

Each deck keeps its own theme, sound and completion state in this browser.
